# System Check

Before your interview, run this quick check to make sure your machine is set up. It takes about a minute.

## Run it

```shell
sh check-prereqs.sh
```

macOS and Linux.

## What it checks

- Java 21 (full JDK, not just a JRE)
- Docker, installed and running
- git and network access
- Claude Code CLI

## If something fails

The script tells you exactly what to install or fix. Fix it and run the check again until you see:

```
ALL CHECKS PASSED
```

If you get stuck on anything, send the full script output to your interview contact and they'll help you sort it out.
